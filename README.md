# ShopSphere

ShopSphere is a small production-like e-commerce platform built
to learn backend development, microservices, AWS, Kubernetes,
CI/CD and GitOps end to end.

## Current Status

Phase 1 — Application Foundation

## Services

- Auth Service
- User Service
- Product Service
- Inventory Service
- Cart Service
- Order Service
- Payment Service

## Technology

- Python
- FastAPI
- PostgreSQL
- Docker
- Kubernetes
- AWS EKS
- Terraform
- Helm
- Jenkins
- ArgoCD
